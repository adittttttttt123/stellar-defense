🚀 HOW TO RUN THE GAME
═══════════════════════════════════════════════════════════════════════════════

METHOD 1: Direct File Open
   1. Open index.html in web browser
   2. Click "PLAY GAME" button
   3. Start playing!

METHOD 2: Local Server (Python)
   1. Open terminal in project directory
   2. Run: python -m http.server 8080
   3. Visit: http://localhost:8080
   4. Open index.html

METHOD 3: Live Server (VS Code)
   1. Open project folder in VS Code
   2. Right-click index.html
   3. Select "Open with Live Server"
   4. Browser opens automatically

METHOD 4: Node.js (http-server)
   1. Install: npm install -g http-server
   2. cd to project folder
   3. Run: http-server
   4. Visit suggested URL

🎯 USAGE INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════════

STARTING THE GAME
   1. Open index.html in browser
   2. Wait for page to load (should be instant)
   3. See menu screen with "PLAY GAME" button
   4. Click button to start

DURING GAMEPLAY
   • Move mouse to position crosshair
   • Click on enemies to destroy them
   • Watch for three enemy types
   • Build combo multipliers
   • Avoid letting enemies reach bottom
   • Watch your score and health in HUD

PAUSE & RESUME
   • Press SPACE to pause
   • Pause menu appears
   • Click "RESUME" or press SPACE again
   • Game resumes from same state

QUIT TO MENU
   • While paused: Click "QUIT" button
   • OR press ESC key
   • Returns to main menu

GAME OVER
   • Triggered when health reaches 0
   • Shows final statistics
   • Click "PLAY AGAIN" to restart
   • Difficulty resets for new game
