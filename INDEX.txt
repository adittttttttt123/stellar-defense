📚 FILE DIRECTORY & DESCRIPTIONS

🎯 CORE GAME FILES
─────────────────────────────────────────────────────────────────────────────

1. 📄 index.html (3.8 KB)
   Purpose: Main HTML structure and entry point
   Contains:
   • Canvas element (game rendering area)
   • Menu screen UI (title, play button)
   • Game screen with HUD overlay
   • Pause menu
   • Game over screen
   • Script imports for all JS files
   Key Elements:
   • <canvas id="game-canvas">
   • HUD display (score, health, combo, timer, wave)
   • Button controls (play, pause, resume, quit)

2. 📄 style.css (6.0 KB)
   Purpose: Styling and visual design
   Features:
   • Press Start 2P pixel font import
   • Color scheme (--primary, --secondary, --accent)
   • Screen transitions and animations
   • HUD styling
   • Button styling with hover effects
   • Responsive design
   • Text glow effects
   Customization: Edit --primary through --warning variables

3. 📄 Enemy.js (1.8 KB)
   Purpose: Base enemy class
   Classes: Enemy
   Key Methods:
   • constructor(x, y, width, height)
   • update(deltaTime, canvasWidth, canvasHeight)
   • render(ctx)
   • isClicked(mouseX, mouseY)
   • hit() - Returns true if destroyed
   Properties:
   • x, y (position)
   • vx, vy (velocity)
   • hp, maxHp (health)
   • points (score value)
   • alive (entity status)

4. 📄 EnemyTypes.js (4.7 KB)
   Purpose: Specific enemy type implementations
   Classes:
   • UFO (extends Enemy)
     - Horizontal movement with bouncing
     - Rotation animation
     - Points: 10
   
   • Meteor (extends Enemy)
     - Diagonal falling motion
     - Spinning animation
     - Points: 15
   
   • AlienTentacle (extends Enemy)
     - Random teleportation
     - Wavy tentacle animation
     - Semi-transparent effect
     - Points: 25
   
   Key Features:
   • Custom render() method per type
   • Unique movement patterns
   • Different visual appearances

5. 📄 Game.js (9.3 KB)
   Purpose: Main game engine and logic
   Class: Game
   Key Methods:
   • constructor(canvas) - Initialize game
   • start() - Begin new game
   • update(deltaTime) - Update game state
   • render() - Draw everything
   • handleClick(mouseX, mouseY) - Process clicks
   • spawnEnemy(type) - Create new enemy
   • createExplosion(x, y) - Particle effects
   • setMousePosition(x, y) - Track cursor
   
   Properties:
   • state (menu/playing/paused/gameover)
   • score, combo, maxCombo
   • health, maxHealth
   • elapsedTime, wave
   • enemies[], particles[] arrays
   • stars[] (starfield)
   
   Features:
   • Game loop management
   • Enemy spawning system
   • Collision detection
   • Particle system
   • Difficulty scaling
   • Combo system
   • HUD updates

6. 📄 UI.js (1.6 KB)
   Purpose: HUD (Head-Up Display) management
   Class: UI
   Key Methods:
   • constructor(canvas, game)
   • update() - Update DOM with game stats
   • formatTime(seconds) - Format time display
   • renderGameOver() - Show final stats
   
   Features:
   • Real-time score display
   • Health hearts display
   • Combo multiplier display
   • Timer display
   • Wave counter display
   • Game over statistics

7. 📄 main.js (4.5 KB)
   Purpose: Game initialization and event handling
   Key Functions:
   • Game initialization (on DOMContentLoaded)
   • Event listeners setup
   • Game loop (requestAnimationFrame)
   • Screen transitions
   
   Event Handlers:
   • Click events (play, pause, resume, quit, restart)
   • Mouse move (crosshair tracking)
   • Canvas click (enemy destruction)
   • Touch events (mobile support)
   • Keyboard (SPACE=pause, ESC=quit)
   • Window resize (canvas scaling)
   
   Global Variables:
   • game (Game instance)
   • animationFrameId (frame request ID)

8. 📄 verify.html (5.0 KB)
   Purpose: Code verification and testing page
   Features:
   • Tests all classes load correctly
   • Verifies all methods exist
   • Provides diagnostic output
   • Color-coded results (pass/fail)
   Usage:
   • Open in browser to verify code integrity
   • Shows status of all game systems
   • Helps troubleshoot issues

🚀 HOW TO USE THESE FILES
─────────────────────────────────────────────────────────────────────────────

TO PLAY THE GAME:
   1. Open index.html in web browser
   2. Click "PLAY GAME"
   3. Move mouse and click to destroy enemies
   4. Build combos and earn points

TO RUN WITH SERVER:
   1. Open terminal in project folder
   2. Run: python -m http.server 8080
   3. Visit: http://localhost:8080
   4. Open index.html

TO UNDERSTAND THE CODE:
   1. Start with README.md (overview)
   2. Read IMPLEMENTATION.md (details)
   3. Review main.js (entry point)
   4. Study Game.js (main engine)
   5. Examine other JS files

TO CUSTOMIZE:
   1. Read IMPLEMENTATION.md (customization section)
   2. Edit the relevant file
   3. Save and refresh browser
   4. Run verify.html to test changes

TO TROUBLESHOOT:
   1. Check PROJECT_COMPLETION.txt (checklist)
   2. Open verify.html (verify code)
   3. Check browser console (F12)
   4. Read QUICK_START.txt (common issues)
